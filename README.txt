MOMENTUM GitHub Pages package

Upload the CONTENTS of this folder to the root of the GitHub Pages repository.

URLs will be:
  https://YOUR-GITHUB-PAGES-DOMAIN/privacy/
  https://YOUR-GITHUB-PAGES-DOMAIN/support/

Support form:
- Uses FormSubmit's AJAX endpoint and submits to momentum_app@icloud.com.
- The mailbox address is not displayed on the page, although it is present in source code.
- After publishing, submit the form once yourself.
- FormSubmit will send a one-time activation/confirmation email to momentum_app@icloud.com.
- Confirm that message before relying on the form for support.
- Once activated, test again and confirm delivery.

Privacy:
- The policy discloses local app storage, optional Apple Health, optional iCloud KVS,
  notifications, and the FormSubmit support-form processor.
- Review the text again if app behaviour changes before release.
